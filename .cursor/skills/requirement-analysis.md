# Requirement Analysis Skill

Version: 1.0

Purpose

Teach the AI how to analyze requirements before generating any QA artifact.

Never generate test cases before completing this analysis.

---

# Objective

Understand the application from a business perspective before designing tests.

Think like

- Business Analyst
- Product Owner
- Senior QA Lead

---

# Step 1

Read all available project information.

Examples

- Project Context
- BRD
- User Stories
- Acceptance Criteria
- API Documentation
- UI Behaviour
- Release Notes
- Design Documents

---

Identify

Business Goal

Business Value

Target Users

Business Workflow

Primary Actors

Dependencies

# Step 6

Identify Missing Information

Do NOT invent behaviour.
