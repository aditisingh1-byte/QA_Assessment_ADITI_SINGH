# Self Review Skill

Version: 1.0

Purpose

Teach the AI to review its own output before presenting the final response.

The AI must act as a Senior QA Lead performing a peer review.

---

# Review Process

After generating any output:

- Requirement Analysis
- Test Scenarios
- Manual Test Cases
- API Tests
- UI Tests
- Automation
- Documentation

perform a complete quality review.

---

# Review Checklist

## Requirement Coverage

Verify

✓ Every Acceptance Criteria is covered

✓ No business requirement is missing

✓ Functional flow is complete

✓ Dependencies are considered

---

## Manual Test Cases

Verify

✓ No duplicate scenarios

✓ No duplicate titles

✓ No duplicate steps

✓ One Expected Result only

✓ Realistic Test Data

✓ Business-focused scenarios

✓ Positive coverage

✓ Negative coverage

✓ Boundary coverage

✓ Edge case coverage

✓ Smoke included

✓ Regression included

✓ Traceability maintained

✓ Automation candidates identified

---

## UI Testing

Verify

✓ Navigation

✓ Validation Messages

✓ Field Validation

✓ User Journey

✓ Browser Consideration

✓ Error Handling

✓ Session Behaviour

✓ Accessibility basics

---

## API Testing

Verify

✓ Authentication

✓ Headers

✓ Payload

✓ Response

✓ Status Codes

✓ Business Validation

✓ Error Validation

✓ Dynamic Data

---

## Automation Review

Verify

✓ Reusable

✓ Maintainable

✓ No duplicate methods

✓ No duplicate locators

✓ Explicit waits only

✓ Assertions included

✓ CI/CD ready

---

## Documentation Review

Verify

✓ Markdown formatting

✓ Grammar

✓ Readability

✓ Consistency

✓ Assessment compliance

---

## CSV Review

Verify

✓ UTF-8

✓ Correct columns

✓ Excel compatible

✓ Proper quoting

✓ No broken commas

✓ No markdown tables

---

## Token Optimization Review

Before responding ask

Can this response be shorter?

Can duplicated information be removed?

Can reusable references replace repeated text?

Can this be split into reusable modules?

Always prefer reusable content over repetition.

---

# Final Validation

Only return the response when

✓ Complete

✓ Accurate

✓ Enterprise Quality

✓ Assessment Ready

✓ Token Optimized
