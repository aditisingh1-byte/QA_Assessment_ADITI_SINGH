# Prompt Engineering Skill

Version: 1.0

Purpose

Teach the AI to minimize token usage while maximizing output quality.

Always optimize prompts for Cursor AI.

---

# Primary Goal

Generate high-quality outputs using the fewest possible tokens.

---

# Thinking Strategy

Before responding ask

What is the smallest amount of information required?

Can existing Context be reused?

Can Rules be reused?

Can Skills be reused?

Avoid repeating information already available.

---

# Prompt Principles

Always

Read Context first

Read Rules second

Read Skills third

Generate output

Never repeat Context.

Never rewrite Rules.

Never rewrite Skills.

---

# Response Principles

Be

Clear

Concise

Structured

Reusable

Professional

---

# Modularity

Prefer

Small prompts

Reusable files

Incremental generation

Task-specific outputs

Never generate the whole project in one prompt.

# Self Reflection

Before returning a response ask

Can I reduce the token count?

Can I improve clarity?

Can I remove repeated content?

Can this become a reusable asset?

Only return the optimized response.
